# 考研政治·史纲时间线

一个真正按历史日期组织考研政治史纲知识的横向时间线学习系统。内容由 82 页史纲强化班笔记结构化生成。

## 功能

- 只保留 PDF 中有正文展开且属于考试要求的授课知识，自动剔除未展开、未讲、明确标注“非重点”或“不考”的内容
- 每项知识归入最重要的年份，同年知识合并为一张节点卡片
- 涉及多个年份时保留“关联时间”，避免丢失前后联系
- 鼠标、触控板与触屏拖动浏览
- 年份、人物、事件与正文全文搜索，选择结果自动定位
- 正文按标题、重点、结论、条目、命题提示和日期分层排版
- 完整知识侧栏、章节快速跳转、缩放与键盘导航
- 本地记录“已学习”状态，无需账号与后端
- 完整 PWA：专用 App 图标、Chrome 安装、独立窗口和离线缓存
- 纯静态资源，可直接部署到 Vercel

## 本地预览

```bash
npm run dev
```

打开 `http://localhost:4173`。

## 内容校验

```bash
npm run check:data
```

重新生成数据时，将 PDF 放在仓库相邻的 `upload` 目录，然后运行：

```bash
python3 scripts/build_content.py /path/to/史纲笔记.pdf
```

## Vercel

在 Vercel 导入本仓库即可。Framework Preset 选择 `Other`，无需构建命令，输出目录留空。部署后在 Chrome 菜单中选择“安装史纲时间线”，即可作为独立应用使用。
